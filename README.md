# Batmon Crowd — landing + fluid cursor
Cursor animation = `src/fluid-cursor.js`, `src/shaders.js`, `src/presets.js` copied unchanged from
https://github.com/tahabakri/fluid-cursor (MIT, engine by Pavel Dobryakov). Only the defaults in
`presets.js` were set to: Ink preset, swirl 30, pressure iters 27, trail fade 0.966, trail width 0.0009.
Run: `npm install` then `npm run dev`.
